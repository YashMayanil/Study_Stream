# 📚 StudyStream — Full Stack Educational Platform

🚀 Live Demo: https://study-stream-fhtiutrsi-yashmayanil87-9461s-projects.vercel.app


---

## 🧠 Overview

**StudyStream** is a full-stack educational video platform built using the MERN stack.
It allows users to explore categorized learning videos, manage their learning journey with favourites and watch later features, and interact with an AI-powered chatbot for better understanding.

---

## ✨ Features

* 🔐 **Authentication**

  * JWT-based login & registration
  * Google OAuth login

* 🎥 **Video Platform**

  * Browse videos by category (DSA, Web Dev, Class 10, etc.)
  * Watch video with YouTube integration

* ❤️ **User Features**

  * Add to Favourites
  * Watch Later functionality
  

* ⚡ **Performance**

  * Lazy loading with React
  * Optimized API calls

---

## 🛠️ Tech Stack

### Frontend

* React.js (Vite)
* Tailwind CSS
* React Router
* Axios

### Backend

* Node.js
* Express.js
* MongoDB (Atlas)
* JWT Authentication
* Google OAuth

### Deployment

* Frontend → Vercel
* Backend → Render
* Database → MongoDB Atlas

## 🚀 Getting Started (Local Setup)

### 1. Clone the repository

```
git clone https://github.com/YOUR_USERNAME/Study_Stream.git
cd Study_Stream
```

---

### 2. Setup Backend

```
cd backend
npm install
npm run dev
```

---

### 3. Setup Frontend

```
cd frontend
npm install
npm run dev
```
